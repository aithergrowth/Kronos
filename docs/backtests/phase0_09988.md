# Phase 0 backtest - Alibaba (HKEX 09988) 5-minute data

**Purpose:** prove the pipeline end to end (data → multi-timeframe views without
look-ahead → bias → POI → confirmation → sizing → paper broker with spread,
stops, targets and break-even → report). This is **not** a strategy verdict:
the instrument is a stock with session gaps, the structure definitions still
carry the assumptions listed in `docs/STRATEGY.md` section 3, and no
calibration against Dorus's chart examples has happened yet.

Dataset: `finetune_csv/data/HK_ali_09988_kline_5min_all.csv` (93,912 five-minute
candles, 2019-11-26 → 2025-09-17), resampled to 15m/1H/4H/1D/1W/1M.
Symbol spec for the run: pip 0.01, pip value 1.0, spread 2 pips, 100k account,
1 % risk. Steps on 15-minute candles. Kronos off.

| Run | Confirmation | Period | Signals | Trades | Win rate | Avg R | Total R | Max DD |
|---|---|---|---|---|---|---|---|---|
| A | first candle allowed | 2024 | 13 | 11 | 9 % | −0.43 | −4.7 | 11.0 % |
| B | BOS/BMS body close only | 2023-01 → 2025-09 | 7 | 6 | 0 % | −0.98 | −5.9 | 5.8 % |

Run A took 178 s for 5,854 steps before swing detection was vectorised; run B
took 265 s for 15,884 steps after.

## What the runs tell us

- **The machinery works.** Every trade had the stop on the correct side, a
  planned R:R ≥ 3, the break-even move fired where 4R was reached, the guard
  blocked a second concurrent trade, and the no-look-ahead views held at every
  step (covered by `tests/trader`).
- **The rule set is extremely selective.** Over 2.7 years the 3/5 bias rule,
  first-visit-only POIs and body-close confirmations produced 7 signals. The
  rejection counters in the report show where candidates die: mostly "price is
  not inside a POI" and "fewer than 3 timeframes agree".
- **The current definitions are not yet Dorus's definitions.** Run B lost every
  trade. With so few trades that is not statistically meaningful, but the
  pattern (entries at the confirmation close, stops just behind the sweep
  wick, targets far away) says the *balance* and *POI* interpretations need the
  answers in `docs/ASTRA_TASKS.md` (Q1, Q2, Q6, Q9) and real examples (B1)
  before parameters are tuned.
- **Stock data hides the forex behaviour the rules were written for.** Session
  gaps break 4H/1H candles and sweeps happen at the open. Phase 2 repeats this
  on cached TradingView forex history.

## How to reproduce

```shell
python -m kronos_trader backtest --symbol 09988 \
  --csv finetune_csv/data/HK_ali_09988_kline_5min_all.csv --base-tf 5m --step-tf 15m \
  --start 2023-01-01 --end 2025-09-17 --kronos off --out trades_bos.csv
python -m kronos_trader backtest --symbol 09988 ... --first-candle --out trades_fc.csv
```
